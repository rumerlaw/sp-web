# Security policy

If you find a security problem on spinanspiritus.com or in this repository, please report it privately and give us a chance to fix it before sharing it publicly.

- Use GitHub's **Report a vulnerability** button on the Security tab of this repository, or
- email spinanspiritus@gmail.com with "Security" in the subject.

Please do not test with real customer data or place real orders, and do not run automated attacks that could slow the site down. We will reply as soon as we can.

Edit your website

Sign in once on this device. After that, open any page of the site and you can click text to change it, click or drop photos to replace them, and drag things into a new order.

How do I get an editing key?
  1. Sign in at github.com, then open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "Website editor". Set an expiration (for example 1 year).
  3. Under Repository access, choose Only select repositories and pick sp-web.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else off.
  5. Click Generate token, copy it, and paste it above.

The key is kept only in this browser. Anyone who has it can change your site, so don't share it. You can delete it any time from the same GitHub page.
